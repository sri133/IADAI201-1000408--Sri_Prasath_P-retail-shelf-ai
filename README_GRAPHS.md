- category_distribution.png

## How to get them out of Colab (only if your runtime is still alive)
```python
import shutil
from google.colab import files
shutil.make_archive("/content/training_graphs", "zip", "/content/runs/shelfsmart_yolo")
files.download("/content/training_graphs.zip")
```
Unzip that on your computer, copy the relevant PNGs/JPGs into this `graphs/`
folder, then upload them to GitHub alongside everything else.
